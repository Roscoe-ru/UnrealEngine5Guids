# UE5 Knowledge Base


Добро пожаловать в мою личную базу знаний!

Здесь я собираю инструкции, полезные советы,
настройки, решения проблем и заметки по работе
с Unreal Engine 5 и дополнительными программами.

Цель этой базы — сохранять полученные знания,
чтобы в любой момент можно было быстро найти
нужную информацию и вспомнить, как выполнить ту
или иную задачу.

# Правила ведения базы знаний

- Все инструкции записываются на русском языке.
- Английские названия инструментов сохраняются
  там, где это необходимо.
- Каждая тема хранится в отдельной папке.
- Для каждой папки создаётся файл README.md.
- К инструкциям можно добавлять скриншоты.
- Новые подразделы можно добавлять в любое время.
